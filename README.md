# Betu & Bholu's Jungle Adventure

Bilingual (Hindi default, English toggle) interactive story game for ages 2-6 with parent co-play.
Stack: Vite + TypeScript + Phaser 3. Static hosting, no backend.

## Quick start

```bash
npm install
npm run slice     # slice sprite sheets in public/assets/source/ into game-ready PNGs
npm run dev       # play at http://localhost:5173
```

## Project map

- `public/assets/source/` - original art drops (scene, character sheets, hats). Never edit; slicer reads from here.
- `public/assets/characters/<id>/<pose>.png` - sliced frames, generated by `npm run slice`.
- `public/assets/hats/hat-white.png` - master hat, tinted in-engine per color.
-  `public/content/chapters/ch1..ch9.json` - the story. Chapters are data, not code: adding ch10 is a new JSON file.
-  `public/content/dialogue/hi.json`, `en.json` - every line keyed by id. Hindi is default; EN is a toggle.
-  `public/content/hats.json` - hat palette + head-anchor tuning per character/pose.
- `src/core/` - AssetManager, ChapterManager, DialogueSystem, Character, HatSystem, SaveManager, AudioManager.
- `src/minigames/` - pluggable mini-games implementing the `MiniGame` interface.
- `website/landing.html` - marketing page linking into the game.

## Story chapters

1. The sunny path + song (tap-along)
2. Rest under the mango tree (eat, drink, massage, nap)
3. The dream (skippable)
4. Betu & Bholu choose hats (HatPicker mini-game) + the theft
5. The discovery
6. The nakalchi idea + dance test (CopycatDance mini-game)
7. The hat throw (CopycatCatch mini-game)
8. The first sale
9. Reprise song

## Conventions

- Outfits never change (see character bible). Hats are a separate layer pinned to head anchors.
- No fail states: mini-games gently retry. Big touch targets.
- New language = one new file in  `public/content/dialogue/`.
- New mini-game = one class implementing `MiniGame`, registered in `StoryScene`.
